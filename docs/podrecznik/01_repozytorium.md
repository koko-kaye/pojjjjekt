# Ćwiczenie 1. Repozytorium z szablonu

**Cel:** zespół ma własne repozytorium, kopię szablonu, a obie osoby mają do niego dostęp.

> [!NOTE]
> **Co to jest szablon?** Repozytorium przygotowane do kopiowania: ma gotowe foldery, kartę projektu i ustawienia Codespaces. Kopia z szablonu jest niezależna: wasze zmiany nie zmieniają szablonu, a zmiany w szablonie nie trafiają do was. Dlatego nie robimy forka.

## Osoba A

1. Wejdź na [github.com/alblesniak/szablon-projektu](https://github.com/alblesniak/szablon-projektu).
2. Kliknij zielony przycisk **Use this template**, potem **Create a new repository**.
3. **Owner:** twoje konto. **Repository name:** krótka nazwa bez spacji i polskich znaków, np. `lalka-recepcja`.
4. Zaznacz **Public** i kliknij **Create repository**.
5. W nowym repozytorium: **Settings → Collaborators → Add people**. Wpisz login osoby B, wybierz ją z listy i kliknij **Add**.

## Osoba B

6. Przyjmij zaproszenie: link w mailu od GitHuba albo na stronie [github.com/notifications](https://github.com/notifications) → **Accept invitation**.

> [!TIP]
> **Dlaczego Public?** Darmowe GitHub Pages działa tylko z repozytoriów publicznych. Surowych danych i kluczy API i tak nie publikujemy, o czym w ćwiczeniu 5.

✅ **Punkt kontrolny:** obie osoby otwierają repozytorium zespołu i widzą README z kartą projektu.
